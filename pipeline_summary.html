1. Overview

This project adapts a US-based utility-scale renewable energy siting analysis to Italy. The modelling framework (pseudo-absence design, GLM + Lasso + Random Forest + GBM, random-effects slope analysis) is identical to the original; changes concern input data sources, coordinate reference system, administrative geography, and predictor variables.

The research question: what spatial, socioeconomic, and policy factors drive the siting of utility-scale solar and wind plants in Italy?

5. Predictor variables in the model

treat ~ tx + roads + sub + slope + pop + fer
      + unemploy + foreignborn + poverty
      + lulc_forest + lulc_grassland + lulc_shrubland + lulc_riparian
      + lulc_sparse + lulc_agriculture + lulc_developed + lulc_other
      + region_nordovest + region_nordest + region_centro + region_sud + region_isole
      + env + cf + lag

25 predictors total (26 terms including intercept). The region_ dummies are one-hot encoded at the pixel level from NUTS-1 rasters.

Random-effects GLMM (figure 4) uses varying slopes by NUTS-1 macro-region:

  • Solar: treat ~ [fixed effects] + (pop + tx + env | region)
  • Wind: treat ~ [fixed effects] + (cf + tx + lag | region)

6. Modelling decisions

Pseudo-absence design

Background points are divided into 10 groups. The model is run once per group (group + presence), and the group with median AIC is selected as the final dataset for ML training. This reduces dependence on the specific pseudo-absence draw.

Machine learning

ModelImplementationNotes
GLM (logistic)glm(..., family = binomial)Baseline; 10-fold CV via caret
Lassocaret / glmnet, α = 1λ grid: 10⁻³ – 10³ (100 values)
Random Forestcaret / rfmetric = ROC; variable importance retained
GBMcaret / gbmReplaces XGBoost: xgboost ≥ 2.0 (v3.2.1.1) is incompatible with caret's xgbTree wrapper; GBM is equivalent in capability

treat encoding: the response is stored in solar.csv / wind.csv as "X0" / "X1" (output of make.names() applied before caret training). data.R converts back to integer 0/1 (as.integer(treat == "X1")) for the GLMM.

Key bugs fixed during Italy adaptation

  • giscoR year: gisco_get_communes(year="2020") invalid → changed to "2016" (most recent available)
  • ISTAT code join: giscoR COMM_ID is "IT101004145" (not 6-digit) → use str_sub(COMM_ID, -6)
  • Foreign-born GENDER filter: column parsed as logical by read_csv → filter(GENDER, ...) not filter(GENDER == "T", ...)
  • pivot_wider missing column: slice_max must be grouped by both REF_AREA and COUNTRY_BIRTH to avoid dropping one birth-country category
  • Group size mismatch: hardcoded rep(10, 8) from US dataset → rep(10, nrow(s.bg) %% 10)
  • Variable label mismatch: GLM drops collinear terms → positional v_name vector misaligned; replaced with named var_labels + rownames_to_column() + recode(var, !!!var_labels)
  • XGBoost ROC all NA: xgboost 3.2.1.1 incompatible with caret xgbTree → replaced with GBM
  • GLMM response type: treat read back from CSV as character "X0"/"X1" → glmer rejected; fixed with as.integer(treat == "X1") at read time in data.R
  • projection@projargs fragile: newer PROJ expands +init=epsg:3035 → regex no longer extracts the EPSG code; replaced with hardcoded st_transform(crs = 3035)

7. RSE Atlante Integrato enrichment

The RSE Atlante Integrato (Ricerca sul Sistema Energetico) provides municipal-level installed renewable energy capacity for Italy, beyond what the GEM trackers cover.

FileTechnologyYearComuni with dataThreshold applied
fv_pot_comunale_2021.shpSolar PV20213,641 / 7,903 (≥0.001 MW)≥1 MW per comune (RSE already filters to ground-mounted, individual plant ≥100 kW)
eo_pot_comunale_2019.shpWind2019362 / 7,926 (≥0.01 MW)≥1 MW per comune. Sources: GSE register, The Wind Power DB, Sentinel-2, ISTAT. No explicit minimum turbine size stated, but all source databases are utility-scale; micro-wind is negligible in Italy.

Join key: PRO_COM (ISTAT numeric province-municipality code, e.g. 71006). Municipality centroids are used as proxy point locations. Duplicates vs. the GEM mask are removed (st_is_within_distance(..., dist = 500)).

Rooftop contamination resolved: RSE explicitly excludes rooftop and small-scale systems (source filter: ground-mounted only, individual plant ≥100 kW). RSE presence points are therefore appropriate for the utility-scale siting research question and are included in both solar_locations and the pseudo-absence mask.

Four-row figure from the random-effects GLMM (fitted in data.R via lme4::glmer). The GLMM allows the slope of selected key predictors to vary by NUTS-1 macro-region, capturing how the importance of each driver differs across Italy.

RowContentVariables shown
A — Solar maps (row 1) Three choropleth maps of Italy at NUTS-1 level, each filled by the region's random slope (deviation from the national average) for one solar driver. Diverging colour scale: orange = negative deviation, blue = positive deviation, white = national average. Population density · Transmission distance · Environmental score
Solar dot-plot (row 2) Horizontal point-range chart with ±1.96 posterior SD intervals, one point per NUTS-1 region per variable, faceted by variable. x-axis is log-odds scale; vertical dashed line at 0 = national average. Same three solar variables
B — Wind maps (row 3) Same choropleth format for three wind drivers. Capacity factor · Spatial lag · Transmission distance
Wind dot-plot (row 4) Same point-range format for wind. Same three wind variables

Purpose: answers "does the same factor matter equally across all Italian regions?" A region whose interval does not cross zero has a statistically distinguishable effect for that variable. For example, transmission distance may be a much stronger positive predictor in the South (where grid infrastructure is less dense) than in the North.

Variable selection rationale: solar uses population density (proximity to demand), transmission distance (grid access), and environmental score (Natura 2000 constraint). Wind uses capacity factor (wind resource quality), spatial lag (clustering of existing wind), and transmission distance.

10. How to run

Open energySiting.Rproj in RStudio first (sets working directory to project root).

Main analysis pipeline (run after any code or data change)

source("run_all.R")

This runs: tech.R → absence.R → zonal.R → modeling.R → data.R → plot.R

If a script fails, the runner prints !! ERROR in <script.R> !! with the message and traceback.

One-time data preparation (run when source data changes)

# Call explicitly — not run by default in run_all.R
run_setup()   # make_base_raster + make_variables_italy + make_socioeconomic + make_natura2000 + stack

Selective re-run

source("syntax/make_natura2000.R")   # rebuild env impact score
source("syntax/stack.R")              # rebuild predictor stack
source("run_all.R")                   # re-run full analysis
